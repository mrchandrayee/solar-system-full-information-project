Interactive HTML/CSS/JavaScript solar-system explorer reconstructed from the supplied video.

## Run

No build step or npm packages required:

```bash
cd solar-system-full-information
python -m http.server 8000
```

Open http://localhost:8000 in your browser. You can also open `index.html` directly.

## Features

- Dark space-themed solar system with Sun and eight planets
- Orbit rings and stylized planet visuals
- Click a planet or its navigation label to show its profile
- Facts include planet type, diameter, day length, year length, moon count and average distance from the Sun
- Responsive layout for desktop and mobile

## Notes

The video shows a compact solar-system diagram and CSS/HTML snippets. The project recreates the visible design and adds a working planet information panel. Orbital sizes and planet sizes are illustrative and are not to scale. Planetary values are approximate; moon counts can change as new objects are confirmed.
